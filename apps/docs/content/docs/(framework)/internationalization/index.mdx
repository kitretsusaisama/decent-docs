## Overview

You'll have to configure i18n routing on your React framework and Decent Docs.

Decent Docs is not a full-powered i18n library, it's up to you when internationalizing the rest of your app.
You can also use other libraries with Decent Docs like [next-intl](https://github.com/amannn/next-intl) on Next.js.
