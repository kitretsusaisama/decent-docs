## Introduction

**Decent Docs is very flexible.** You can integrate with any content source, even without an official adapter.

### Examples

The content source page of your app can read from a CMS, which allows a nice experience on publishing content, and real-time update without re-building the app. See the [local dev server](/docs/integrations/content/satteri-local-md) for a self-hosted setup.

Not enough? [Build your own content source](/docs/integrations/content/custom).
