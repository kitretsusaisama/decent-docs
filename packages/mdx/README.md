# @decentdocs/mdx

The built-in source for Decent Docs: MDX content collections, the
build pipeline, and the `source.config.ts` loader. Provides the
`decent-mdx` CLI.

## Install

```sh
npm i @decentdocs/mdx
```

## Usage

```sh
decent-mdx --help
```

Part of the Decent Docs platform.

Documentation: https://github.com/kitretsusaisama/decent-docs
