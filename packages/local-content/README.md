# @decentdocs/local-content

Shared building blocks for local content sources in Decent Docs,
including the `decent-local-md` dev server that proxies local Markdown
files to a running site.

## Install

```sh
npm i @decentdocs/local-content
```

## Usage

```sh
decent-local-md dev -- next dev
```

Part of the Decent Docs platform.

Documentation: https://github.com/kitretsusaisama/decent-docs
