# @decentdocs/cli

The command center for Decent Docs: configure features (docs, llms, mcp,
search, og, lint), run codemods, and scaffold files in an existing app.

## Install

```sh
npm i -g @decentdocs/cli
```

## Usage

```sh
decent-docs --help
decent-docs init
```

Part of the Decent Docs platform.

Documentation: https://github.com/kitretsusaisama/decent-docs
